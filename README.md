# Submariner — A Study in Time

Responsive cinematic Rolex Submariner Date concept website. The watch is genuine product photography; depth and cinematic motion come from layered layout, parallax and scroll animation—not a 3D watch model.

## Run locally
Open `index.html`, or run `python -m http.server 8000` and visit http://localhost:8000.

## Deploy to Vercel
1. Create a GitHub repository and upload the contents of this folder to its root.
2. In Vercel choose **Add New → Project** and import the repository.
3. Framework preset: **Other**. Build command: blank. Output directory: `.`.
4. Deploy.
